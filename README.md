# @aeos/v4

Aeos v4 static distribution and single-file launcher.

## Usage

### JSR
Import the module using [JSR](https://jsr.io/@aeos/v4):

```ts
import { getInfo, version } from "@aeos/v4";

console.log(version);
console.log(getInfo());
```

## Contents
This package includes the complete Aeos v4 distribution bundle:
- `dist/` — Compiled web application, themes, launcher components, and player assets.
- `singles/` — Standalone single-file bootstrap launcher (`aeos-v4.html`).
